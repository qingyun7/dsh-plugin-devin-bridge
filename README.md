# Devin 桥

在 DSH 里用 Devin 模型聊天。支持浏览器登录、筛选聊天模型，以及查看每日和每周用量。

## 安装和使用

1. 在 DSH 的「插件 → 安装第三方插件」中，粘贴安装包的下载地址或本机路径。
2. 打开「设置 → Devin 桥」登录。浏览器登录需要先安装 Devin 桌面版或支持浏览器登录的 Devin CLI。
3. 点击「从 Devin 拉取模型」，勾选并保存后，就能在聊天框里选用这些模型。

已在 DSH 0.2.2-rc.1 桌面版验证。
